ABOUT 05 / 05

POOPBOT MENU V2 is a standalone Quest-friendly VR interface. It is not connected to Gorilla Tag and does not modify another game. Menu navigation, visual preferences, audio controls and local settings are functional.

WebXR availability depends on the browser, HTTPS origin and headset support. This project is an installable web app, not a native APK.
